# Badbaado — Mobile (Flutter)

Native iOS/Android app for the Badbaado emergency platform. Uses the same `badbaado-backend`.

## Astaamaha (Features)
- **Auth** — login/register, JWT access + **refresh** (Dio interceptor), tokens in secure storage.
- **SOS** — press-and-hold button → alert + GPS (geolocator).
- **Cod/Video** — record audio (`record`) & video (`image_picker`) as evidence, upload to backend.
- **Live map** — `flutter_map` (OpenStreetMap) + **Socket.IO** live member markers.
- **CRUD** — circles (create/join), members, alerts.
- **3 luqadood (i18n)** — Soomaali / Carabi (**RTL**) / Ingiriis (live switch).
- **Dark / Light mode** — toggle, persisted.

## Setup
> Flutter SDK 3.x required.

```bash
# 1) generate the platform folders (android/ios) without touching lib/ or pubspec.yaml
flutter create .

# 2) get packages
flutter pub get

# 3) add permissions:
#    - merge android-snippets/AndroidManifest-permissions.xml into android/app/src/main/AndroidManifest.xml
#    - merge android-snippets/Info-plist-permissions.xml into ios/Runner/Info.plist

# 4) run (point to your backend; Android emulator reaches host via 10.0.2.2)
flutter run --dart-define=API_BASE=http://10.0.2.2:5000/api/v1 --dart-define=SOCKET_URL=http://10.0.2.2:5000
```

## Structure
```
lib/
  config/    env.dart, theme.dart (light/dark)
  services/  api_service.dart (Dio + refresh), socket_service.dart, location_service.dart, token_store.dart
  providers/ auth_provider.dart, theme_provider.dart, locale_provider.dart
  l10n/      app_strings.dart (so/ar/en)
  widgets/   sos_button.dart, recorder_sheet.dart, brand_header.dart, lang_theme_row.dart
  screens/   splash, login, register, home (bottom nav), dashboard, map, alerts, profile, circles
```

> Note: lib/ + pubspec.yaml are provided. Platform folders are generated by `flutter create .`
> (it won't overwrite existing Dart files).
